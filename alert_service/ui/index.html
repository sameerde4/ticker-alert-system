Sentiment scoring

Headline scorer

FinBERT is the ProsusAI/finbert model. The first check downloads its weights. After that, PyTorch scores headlines on this computer. It is not a hosted analysis API, so there is no daily request cap. Each headline is cut off at 512 tokens. The model returns a probability for positive, negative, and neutral. The stored score is the positive probability minus the negative probability, from −1 to 1. The alert line names the winning class and those three probabilities.

Custom scoring is the finance word list copied from Vajra Astra. It does not load a model. Each word is looked up for a signed weight. A negation in the previous three words flips that word. The score is the average weight of the matched words, multiplied by the number of hits divided by 3, and capped at ±1. One mild hit stays near ±0.33. The alert line names the matched words.

A check uses only the selected scorer. The two scores are never averaged. Both use the same absolute threshold. The next check rescores every saved headline and can replace today’s alert.

Rebuild history

Admin test tool. Deletes every saved alert, then reruns the current price and sentiment rules for each watchlist symbol over the last X calendar days, including today. Price uses each session’s close. Headlines are the stories already stored plus the recent list Yahoo returns now, and each story stays on its publish day.
